# Harness Workspace — object-centered spatial UX prototype

Интерактивный прототип сложного рабочего пространства, где центральный
документ остаётся смысловым центром, а структура, свойства, инструменты и
системная активность живут на разных слоях глубины.

**Демо:** https://2025viktordva-web.github.io/object-centered-spatial-ux-prototype/

## Что можно проверить

- четыре композиции визуального веса в режиме **Design Lab**;
- скрытие и раскрытие структуры и свойств без смены экрана;
- три состояния нижней инструментальной поверхности;
- связанное выделение разделов документа, свойств и инструментов;
- контекстный лоток и отдельный слой активности AI-агента;
- самостоятельную мобильную композицию с временными выдвижными панелями.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Технологии

React, TypeScript, Vite/vinext, обычный CSS с custom properties,
`lucide-react` и локальный variable-шрифт Manrope через `@fontsource`.

Прототип демонстрационный: данные не сохраняются, серверная бизнес-логика,
авторизация и совместное редактирование не реализованы.
